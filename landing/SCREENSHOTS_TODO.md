# Screenshot & Asset Integration TODO

This landing page currently uses hand-built CSS/HTML mockups as stand-ins for real
product screenshots, and single-letter colored badges as stand-ins for real feed/brand
icons. This file tracks everything that needs to be swapped for the real thing, grouped
by platform. Check items off as they're integrated.

**How to integrate**: replace the described mockup `<div>` block in `index.html` with
an `<img>` (or a device-frame wrapper around one) pointing at a real exported asset in
`landing/assets/img/` (create this folder when the first real asset lands). Keep the
existing `border-radius` / `box-shadow` / `overflow:hidden` wrapper styling so the new
image sits in the same frame — the mockups were sized to match likely real dimensions,
but double-check crop/aspect ratio once you have the real capture.
